# 🚀 NLW Pocket — Iniciantes | Rocketseat

> Repositório desenvolvido durante o evento **NLW Pocket** da [Rocketseat](https://rocketseat.com.br/), na trilha de Iniciantes, com foco em inteligência artificial aplicada e engenharia de prompts.

---

## 📌 Sobre o Projeto

Este repositório reúne os materiais e a aplicação web desenvolvidos durante o NLW Pocket. O projeto é dividido em duas partes principais:

- **`prompts-main`** — Coleção de prompts práticos para uso com modelos de linguagem (ChatGPT, GPT-3.5, GPT-4 etc.), cobrindo desde técnicas básicas até padrões avançados de engenharia de prompts.
- **`prompts_manager`** — Aplicação web para gerenciar, criar, salvar e copiar prompts diretamente no navegador.

## 🖥️ Prompts Manager — Aplicação Web

Uma aplicação web leve, construída com **HTML, CSS e JavaScript puro**, para organizar e gerenciar seus prompts diretamente no navegador.

### ✨ Funcionalidades

- ✅ **Criar prompts** com título e conteúdo editável
- 💾 **Salvar prompts** no `localStorage` (persistência local)
- 📋 **Copiar prompts** rapidamente para a área de transferência
- 🔍 **Buscar prompts** por texto
- 📂 **Sidebar retrátil** para navegação entre os prompts

### 🛠️ Tecnologias Utilizadas

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

- **Fonte:** [Inter](https://fonts.google.com/specimen/Inter) (Google Fonts)
- **Armazenamento:** `localStorage` do navegador
- **Sem dependências externas** — 100% vanilla

### ▶️ Como executar

1. Clone o repositório:
```bash
git clone https://github.com/victoralecrim11/NLW-Pocket_Iniciantes-Rocketeseat.git
```

2. Acesse a pasta da aplicação:
```bash
cd NLW-Pocket_Iniciantes-Rocketeseat/NLW-Pocket-iniciantes/prompts_manager
```

3. Abra o arquivo `index.html` no seu navegador.

> Não é necessário nenhum servidor ou instalação de dependências.
